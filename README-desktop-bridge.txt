眼息 - 网页界面 + 电脑强提醒版

启动方式：
1. 双击 Start-EyeRest-Web.bat
2. 程序会启动“眼息本机桥接”小窗口，并自动打开网页
3. 在网页的“提醒方式”里开启“交给电脑强提醒计时”
4. 选择强提醒方式：全屏遮罩 / 屏保 / 锁屏

说明：
- 网页本身不能直接锁屏或系统级霸屏，这是浏览器安全限制。
- Start-EyeRest-Web.bat 会在本机启动一个桥接服务，地址是 http://127.0.0.1:17891
- 点击“开始”时，网页会把倒计时任务交给本机程序；切到其他窗口、其他标签页后，本机程序仍会准时执行全屏遮罩、屏保或锁屏。
- 如果本机程序没有确认接管计时，网页会直接提示失败，不会继续假装能自动锁屏。
- 全屏遮罩会由独立的短时进程弹出，不再依赖网页窗口或桥接窗口是否在前台。
- 暂停、重置或切换模式时，网页会同步取消或更新本机计时任务。
- 关闭“眼息本机桥接”小窗口后，电脑强提醒会停止；网页会自动退回普通页面提醒。
- 建议默认使用“全屏遮罩”。“锁屏”会立即打断当前工作。
